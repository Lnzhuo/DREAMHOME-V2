# BYOK 安全与使用边界

配置仅在服务端内存中以 AES-256-GCM 加密保留，随机主密钥只存在进程内，随机 HttpOnly SameSite=Strict 会话 Cookie 标识会话。重启或 24 小时会话到期后需要重新填写；无用户账号，不承诺跨设备恢复。密钥不会写入项目或浏览器存储。设置可选择平台或个人服务、保存替换、删除，并以只读任务列表或 /models 测试。个人 Key 的调用费用由个人账户承担。

服务仅监听本机。生产部署必须由可信反向代理提供 HTTPS，并设置 COOKIE_SECURE=true 和 ALLOWED_HOSTS（逗号分隔允许的主机名）；需部署访问控制、网络隔离以及安全的主机级管理。个人 LLM 地址仅允许公网 HTTPS；连接时检查 DNS 结果并禁止回环、私网和链路本地地址，拒绝重定向。平台管理员可在本项目环境变量中配置本机回环服务。LLM Key 仅交给用户选择的服务，禁止向不可信服务提交。/models 鉴权成功不等于模型能执行多模态。场景命令需校验和用户确认，图片仅作为视觉上下文，并非精确重建。

平台网页生成仅在显式设置 LUX3D_ALLOW_PAID_GENERATION=true 后可用，和专用批次共用持久化冻结账本及互斥锁；每个任务冻结 20 积分，失败、取消和结果不明均不释放，新增冻结上限为 3540。官方 tasks.list 可按 taskId 只读取得 consumedCredits；它是任务接口报告的积分字段，退款及最终余额仍以账户账单核对。账户控制台余额作为带时间的独立快照，不以预估值推算实际余额。遗留锁需要人工核查，不自动解除。个人 Key 费用由个人账户承担，平台与个人账户不混算。

## 本地模型与图片入口

本项目可通过平台配置连接本机 llama.cpp 的 OpenAI 兼容 `/v1/chat/completions`；已使用 Qwen3-VL-4B-Instruct Q4_K_M 和 Q8_0 mmproj 做浏览器联调。设计助手的“参考图片”会在本机提取参考色，并将实际图片、文字与精简场景上下文通过 `/api/ai/scene-command` 发给所选模型。个人外部模型使用公网 HTTPS 路径，并须支持视觉输入才能处理图片。

已验证：模型生成原木茶几向右移动 20 厘米的命令，应用后可撤销；蓝色色样辅助下生成沙发 `#174a9f` 改色，确认后刷新仍保留。图片理解的验收仅覆盖该色色样任务；证据见 `docs/verification/v2/local-ai/ai-e2e.json`。模型返回先经过校验和预览，用户确认后才应用。
