# DREAMHOME V2 交付说明

截至 2026-11-19 22:53 中国标准时间，DREAMHOME 已可从空房或平层户型创建、保存、分享住宅设计。Phase 3/4 的 Three.js、编辑器、IndexedDB 存档和三件真实 Lux3D 家具继续使用。原版代码保存在本机 Git 的 phase4 分支，V2 在 dreamhome-v2 分支开发。

## 打开与演示

1. 将 Windows 主包完整解压，双击「启动DREAMHOME.cmd」，打开 http://127.0.0.1:4196 。服务只监听本机。使用同一浏览器和地址可继续此前设计。
2. 首页选择「打开三室两厅样板房」，可以从整套开始。也可在 13 类空房或 10 套平层中选一个，点「手动调整」后在右侧填写实际尺寸。
3. 在左侧点「Lux3D 原创」，搜索家具并预览。点「放入房间」或拖到地面。平面摆放使用真实俯视图；切到 3D 可查看材质、尺寸或漫游。
4. 在材料库更换墙地面或选中的家具。点击「保存项目」保存版本，通过「设计文件」导出 .dreamhome。安装本地 AI 扩展包后可直接让设计助手改动场景；也可在「API 管理」使用自己的服务。
5. 本地多模态扩展包解压到与主包相同的位置，保留 data/local-ai 目录结构。关闭旧启动窗口，重新双击启动。云端 Lux3D 需要网络和有效凭据，基础编辑、已归档资产和已安装的本地推理均可在本机工作。

## 源码与复核

开发入口为 npm ci、npm run dev。生产构建为 npm run build，运行 npm start。离线 Windows 包自带 Node 及依赖，可以直接双击启动。完整验收步骤、截图、演示素材和专项回归见 DREAMHOME_V2_ACCEPTANCE.md 及 verification/v2。资产来源、许可与生成来源分别在 ASSET_LICENSE_LEDGER.csv 和 LUX3D_CREDIT_LEDGER.csv 登记。

公网体验地址为 https://dreamhome.8-218-155-239.sslip.io/ 。网站提供 /release.json 记录当前版本，可比对其中 indexSHA256 与随包 docs/verification/release-snapshot.json。应用源码在 https://github.com/Lnzhuo/DREAMHOME-V2 ，各次上线对应的提交与公网浏览器记录随交付提供。庭院与建筑参数用于概念设计展示。现有窗洞、开间、门扇和实物尺寸仍需以现场测量为准。
